Sudoku for reMarkable Paper Pro

A Sudoku game for the color e-ink display. It is the best way to play Sudoku: it feels like pen and paper, and it does the work that paper cannot do.

Installation

You need a reMarkable Paper Pro and a computer with macOS or Linux. Run this command in a terminal of the computer:

curl -fsSL https://github.com/garbles/sudoku/releases/latest/download/install.sh | bash
  1. The installer downloads the latest release and examines its checksum.
  2. It finds the tablet on the USB cable. If developer mode is off, it tells you how to turn it on.
  3. It makes an SSH key and adds it to the tablet. For this, you type the SSH password of the tablet one time.
  4. It installs Vellum and the AppLoad launcher, and starts xovi. The tablet must be connected to Wi-Fi.
  5. It copies Sudoku to AppLoad. Open AppLoad on the tablet and tap Sudoku.
Developer mode erases all data on the tablet. Sync your notebooks to the cloud first.

Run it again

  • After a restart of the tablet, AppLoad is not in the menu. Run the installer again to start xovi.
  • To install a new version. Sudoku also tells you about new versions in its Settings panel.
  • To use Wi-Fi in place of the USB cable, set REMARKABLE_HOST=<address> before bash.

For the manual installation and the build, refer to the README. Downloads are on the Releases page.
