Sudoku GitHub

Sudoku for reMarkable Paper

Simply the best way to play Sudoku.
Feels like pen and paper.
Does the work that paper cannot.

Installation

You need a reMarkable Paper Pro or Paper Pro Move in developer mode and a computer with macOS or Linux. Run this command in a terminal of the computer:

curl -fsSL https://github.com/garbles/sudoku/releases/latest/download/install.sh | bash

For the manual installation and the build, refer to the README. Downloads are on the Releases page.
